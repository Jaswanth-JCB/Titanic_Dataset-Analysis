# Titanic Dataset Analysis

## Project Description
This project analyses the Titanic passenger dataset using PostgreSQL, Python and Streamlit.

## Technologies Used
- PostgreSQL 18
- Python
- Pandas
- Streamlit
- Psycopg2
- pgAdmin 4

## Dataset
The dataset contains 891 passenger records with details such as passenger name, age, gender, class, fare and survival status.

## Database
Database name: titanic_db

Schema name: titanic_project

Main table: passengers

## Project Features
- Passenger data analysis
- Passenger count by gender
- Passenger count by class
- Average age by class
- Survival analysis
- Data visualisation using charts

## How to Run

1. Install Python.
2. Install required libraries:

   pip install streamlit pandas psycopg2-binary

3. Configure PostgreSQL connection in `.streamlit/secrets.toml`.
4. Run the application:

   streamlit run app.py
